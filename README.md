[Homebrew] taps for [ZuBB]'s patches & utilities. Updated _randomly_.

## Getting Started

To install any of the formulas below:

1. Tap the repository:

    ```sh
    brew tap ZuBB/tap
    ```

2. Install a formula:

    ```sh
    brew install <name>
    ```
